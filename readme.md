## 📋 Descripción
Herramienta computacional para el cálculo completo de parámetros y comportamiento de líneas de transmisión eléctrica. Incluye:
- Cálculo de resistencia, inductancia y capacitancia
- Impedancia y admitancia
- Modelo nominal π
- Análisis en recepción y envío
- Efecto Ferranti
- Eficiencia y regulación de tensión
- Soporte para líneas **monofásicas** y **trifásicas**

## 📊 Datos del Ejercicio Base
- Longitud: 230 km
- Frecuencia: 50 Hz
- Tensión de línea: 50 kV
- Carga: 120 MW
- Factor de potencia: 0.85 inductivo
- Resistencia: 0.052 Ω/km
- Radio del conductor: 27 mm
- Distancias entre conductores: 6 m, 6 m, 12 m

## 🚀 Cómo usar
1. Abrir la carpeta en **Visual Studio Code**
2. Abrir `index.html`
3. Hacer clic derecho → "Open with Live Server" o abrir en el navegador
4. Seleccionar tipo de línea
5. Modificar datos si es necesario
6. Presionar **Calcular Todo**
